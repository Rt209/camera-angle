# Geometry Based Pose Breakdown

這是既有 geometry-based single image pose pipeline 的 breakdown。

此技術路線以單張影像中的幾何線索為核心：

- line detection
- horizon detection
- vanishing point detection
- yaw / pitch / roll integration
- confidence scoring
- debug artifacts
